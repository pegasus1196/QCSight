CAPABILITIES

Comprehensive Quality Control

Five inspection checks plus a planned detection module

Device Presence

Verifies every component from the GA drawing exists in the built cabinet using contour matching and feature detection.

ORB + SIFT

Label Verification

OCR reads printed device labels and fuzzy-matches them against the design's expected label list.

EasyOCR + RapidFuzz

Wire Ferrules

Detects ferrule markings on wire ends using region-of-interest OCR and validates against the wire list.

ROI + OCR

Photo Alignment

Feature-based homography registers the cabinet photo against the GA drawing layout with SSIM scoring.

Homography + RANSAC

Wire Colour

HSV colour space analysis with K-means clustering validates wire colours against IEC 60445.

K-Means + HSV

Component Detection

Planned for Round 2: YOLOv8 → ONNX Runtime for automated component localisation across electrical cabinets.

UNDER THE HOOD

Current Prototype Stack

Built on proven computer vision frameworks

ORB / SIFT

Oriented FAST and Rotated BRIEF for fast keypoint detection. Scale-Invariant Feature Transform for robust descriptor matching with BFMatcher and Lowe's ratio test.

Feature DetectionKeypoint MatchingRANSAC

Deep learning OCR with CRAFT text detection and CRNN recognition. CLAHE preprocessing enhances contrast for industrial label reading. Pytesseract fallback for edge cases.

WORKFLOW

How It Works

Five-step closed-loop pipeline from upload to verified fix

01

Upload

Add your cabinet photo, GA drawing, wire list, and label list. All files stay on your device — zero cloud dependency.

02

Configure

Select which checks to run and set your confidence threshold for precision-first analysis.

03

Analyze

ORB/SIFT, OCR, and HSV colour pipelines process your images with detailed evidence per check item.

04

Suggested Fix

Every FAIL gets a step-by-step corrective suggestion — which tool, where to fix, and how to verify the repair.

05

Re-Check

Fix the issue, re-photograph, and re-run. Closed-loop verification marks resolved items CLOSED automatically.
